BECKLAN GITHUB ICON PACKAGE

Upload all files and the icons folder to the ROOT of the GitHub repository.

Required root files:
- index.html
- config.js
- app.js
- styles.css
- manifest.webmanifest
- service-worker.js
- apple-touch-icon.png
- favicon-16x16.png
- favicon-32x32.png
- icons/ folder

The Becklan logo will be used as:
- Installed app/PWA icon
- Android home-screen icon
- Apple touch icon
- Browser favicon
- Clickable launcher on the GitHub page

The configured launcher opens the deployed Becklan Apps Script web app.
